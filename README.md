## هيكل المشروع

* `index.js`: نقطة تشغيل البوت الرئيسية وإدارة اتصال واتساب.
* `handler.js`: محرك معالجة الرسائل وتوجيه الإضافات بكفاءة عالية.
* `config.js`: إعدادات المالك، الحقوق، الأرقام، الروابط، والصورة الرسمية.
* `plugins/`: أوامر وإضافات البوت البرمجية الخاصة بك.
* `lib/`: المكتبات البرمجية والأدوات المساعدة المطورة خصيصاً للنظام.
* `data/` و`src/database/`: قواعد بيانات البوت وأنظمة التخزين المحلي.
* `tmp/`: مساحة المعالجة المؤقتة للملفات.
