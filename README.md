## نبذة عن البوت

**𖣂 𝐃𝐚𝐦𝐨𝐧 𝐁𝐨𝐭** هو بوت واتساب يهدف إلى توفير مجموعة من الوظائف والأوامر
داخل المحادثات والمجموعات، مع نظام إضافات &#40;Plugins&#41; يسمح بتنظيم الأوامر
وتوسيعها، إلى جانب ألعاب تفاعلية تحفظ تقدم اللاعبين وبياناتهم\.

يعتمد تشغيل الأوامر على بادئة افتراضية هي النقطة `.`، ويمكن أن تختلف إذا
تم تعديل إعدادات المشروع\.

## المميزات

- نظام أوامر مبني على الإضافات لتسهيل تنظيم الوظائف وتطويرها\.
- دعم أوامر داخل المحادثات الخاصة والمجموعات بحسب إعدادات كل أمر\.
- نظام صلاحيات للمالك والمطور والنخبة\.
- أوضاع للتحكم في استقبال الأوامر الخاصة ووضع النخبة\.
- ألعاب تفاعلية تشمل المغامرات والنجاة والكنوز والمبارزات\.
- حفظ بيانات الألعاب مثل المستوى والصحة والخبرة والذهب\.
- قوائم وأزرار تفاعلية، مع رسائل نصية بديلة عند تعذر عرضها\.

## طريقة استخدام الأوامر

اكتب الأمر مع البادئة `.`، مثال:

```text
.العاب
```

بعض الأوامر الأساسية قد تكون متاحة بصيغ مباشرة مثل `تست` و`بوت` و`mode`
وفق إعدادات المشروع\.
